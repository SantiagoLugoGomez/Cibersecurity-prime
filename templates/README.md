# Templates

Copy one of these into your notes or your portfolio and fill it in. Each links to the knowledge-base page that explains the thinking behind it.

| Template | Use it for | Where it is taught |
|---|---|---|
| [weekly-note.md](weekly-note.md) | Your private, per-week study log (R, P, D, E sessions) | [The study system](../docs/11-learning-and-career/02-the-study-system.md) |
| [weekly-review.md](weekly-review.md) | Your Sunday review slot | [Study load modes](../docs/11-learning-and-career/03-study-load-modes.md) |
| [threat-model.md](threat-model.md) | A STRIDE threat model for a system or feature | [Threat modeling](../docs/01-foundations/03-threat-modeling.md) |
| [detection-rule.md](detection-rule.md) | Documenting one detection, from hypothesis to test result | [Detection engineering](../docs/07-defensive-security/02-detection-engineering.md) |
| [incident-postmortem.md](incident-postmortem.md) | A blameless postmortem after a real or simulated incident | [Incident response](../docs/07-defensive-security/04-incident-response.md) |
| [risk-register.md](risk-register.md) | Tracking risks for a system or organization | [Risk management](../docs/10-governance-risk-and-compliance/01-risk-management.md) |
| [pentest-report.md](pentest-report.md) | A formal, client-style engagement report | [Penetration testing methodology](../docs/06-offensive-security/01-penetration-testing-methodology.md) |
| [../writeups/TEMPLATE.md](../writeups/TEMPLATE.md) | A single machine, CTF challenge or lab writeup | [Portfolio and writing](../docs/11-learning-and-career/06-portfolio-and-writing.md) |

Before publishing anything built from these in your public portfolio, run the self-audit in [Portfolio and writing](../docs/11-learning-and-career/06-portfolio-and-writing.md#before-you-publish-an-osint-self-audit).
