# Reading and resource list

Everything referenced across the roadmap, in one place, so you can see what to read, when, and whether it is free. Prices and versions were checked in October 2026; reconfirm before buying anything.

## How to use this list

- **Free first.** Every phase can be completed with the free resources alone. Paid items are optional and marked.
- **Read for the phase you are in.** The "When" column points to the phase or module. Do not front-load books you will not use for months.
- **Primary sources beat summaries.** Where an RFC, standard or vendor doc is listed, prefer it over a blog about it.
